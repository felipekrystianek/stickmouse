# Changelog

Each release is a `## <version> - <date>` heading with a plain list of changes. The build turns the
newest entries into the release notes Stickmouse shows when it offers an update
(`website/appcast.xml`) and into the changelog page (`website/changelog.html`).

## 1.1.0 - 2026-11-07

- Stickmouse now updates itself: when a new version is out, it shows what changed and installs it with one click.
- New "Check for Updates…" item in the menu bar menu.

## 1.0.0 - 2026-11-06

- First stable release.
- Tidier License and Setup windows.
- Bug reports now go to the Stickmouse repository on GitHub.
